# dadex-website

Objavljeni sajt firme **Dadex d.o.o.** — https://milandavid.github.io/dadex-website/

Sadržaj ovog repoa je **generisan**: pravi ga workflow `mirror.yml` iz
privatnog repoa [`MilanDavid/dadex`](https://github.com/MilanDavid/dadex)
na svaki push na `main`. Ručne izmene ovde biće prebrisane sledećim
build-om — menjaj izvorni repo.
